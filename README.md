# Arc

**The Studio-in-a-Box. From Brainstorm to Blockbuster Pitch.**

## Overview
Arc is an AI-powered SaaS platform designed to guide screenwriters through the entire lifecycle of film development. It combines structural narrative rigor with generative media assets to help writers not just write, but sell their movies.

## Core Features
- **Dual-Mode Onboarding**: Explorer (for Pantsers) and Architect (for Plotters).
- **The "Universe" Architecture**: RAG-powered Project Bible for continuity.
- **Game Theory Logic Engine**: Mathematical stress-testing of plot holes.
- **Asset Pipeline**: Generative studio for characters, posters, and teasers.

## Tech Stack
- **Frontend**: Web Application (Framework TBD)
- **Backend**: Python / Firebase Genkit
- **Database**: Firestore + Vector Search
- **AI**: Gemini 1.5 Pro, Nano Banana Pro, Google Veo 3
