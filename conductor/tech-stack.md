# Tech Stack: ArcWriter

## Frontend
- **Framework:** React
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Routing:** React Router DOM
- **Charts:** Recharts
- **SDK:** Firebase JavaScript SDK

## Backend
- **Framework:** FastAPI
- **Web Server:** Uvicorn
- **Language:** Python 3.8+
- **PDF Processing:** ReportLab, pypdf, pdfplumber
- **Payments:** Stripe SDK

## AI & Data
- **AI SDK:** Google GenAI (Gemini 1.5 Pro)
- **Generative Media:** Vertex AI (Imagen, etc.)
- **Primary Database:** Firebase Firestore (Real-time script saving)
- **Metadata Storage:** Structured Local File System (Universes/Projects)
- **Object Storage:** Google Cloud Storage (Firebase Storage)

## Infrastructure
- **Hosting:** Firebase Hosting
- **Compute:** Firebase Functions (Serverless backend components)
- **Auth:** Firebase Authentication
